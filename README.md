#  Social Bookmarking & Image Sharing Platform

##  Overview

A Django-based web application where users can bookmark images from other websites, upload and share their own images, and interact with other users.

##  Key Features

-  **JavaScript Bookmarklet:** Bookmark images from external websites with one click.
-  **User Authentication:** Sign up, log in, log out, and reset passwords.
-  **Google Login:** Sign in using a Google account.
-  **User Profiles:** Manage profiles and upload profile pictures.
-  **Image Sharing:** Upload, bookmark, and share images.
-  **Like System:** Like images shared by other users.
-  **Image Feed:** Explore images shared on the platform.
-  **Image Details:** View image information and its original source.

##  Technologies Used

- Python & Django
- JavaScript
- HTML & CSS
- Google OAuth
- Git & GitHub
